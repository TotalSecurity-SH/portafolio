Modular ERP for a network of 34 branches

The challenge

Each branch's daily sales were consolidated by hand in spreadsheets, and IT issues arrived through chat messages with no tracking or history.

What I built

  • Clean-architecture API with JWT and an audit log
  • Nightly sales sync from the branch system's API
  • Service desk with automatic assignment by category
  • Self-hosted deployment with WAF and off-site backups
